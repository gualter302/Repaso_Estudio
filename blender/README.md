# Blender (fines de semana, opcional)

> Esto es por gusto. Sin metas de horas y sin culpa si un fin de semana no lo tocas.

- Descargar: [blender.org/download](https://www.blender.org/download/) (gratis)
- Tu tarjeta gráfica NVIDIA permite renderizar con **Cycles** usando la GPU: Edit → Preferences → System → CUDA u OptiX.

## Ruta sugerida

### Nivel 1: Moverte por la interfaz
- [ ] Navegar la vista: rotar, hacer zoom, desplazarte, vistas del teclado numérico
- [ ] Seleccionar, mover (G), rotar (R), escalar (S)
- [ ] Modo objeto vs. modo edición
- [ ] Atajos básicos: extruir (E), insetar (I), bisel (Ctrl+B), loop cut (Ctrl+R)

### Nivel 2: El tutorial de la dona
- [ ] Serie de la dona de **Blender Guru** en YouTube (el punto de partida clásico)
- [ ] Guardar aquí el render final: `dona.png`

### Nivel 3: Algo tuyo
- [ ] Modelar un objeto de tu casa (una taza, una lámpara, una silla)
- [ ] Materiales y una iluminación sencilla
- [ ] Render final en esta carpeta

### Nivel 4: Conectar con lo que ya sabes (opcional)
- [ ] Exportar un modelo a `.fbx` e importarlo en **Unity** (como en tu proyecto del Arduino)
- [ ] Explorar los scripts de Python dentro de Blender (Scripting): sí, el mismo Python de la fase 1
