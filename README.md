# Repaso_Estudio
Repositorio creado con el proposito de aprender mejor sobre programacion y sus fundamentos y tener una mejor logica y comprendimiento de lo que se esta haciendo

> **Regla de oro:** si no puedo explicar una línea de código, no la pego.

---

## 🎯 Objetivo

Repasar y dominar los fundamentos que la carrera da por sabidos, y terminar con un proyecto propio (web + base de datos) que pueda explicar de principio a fin.

- **Camino principal:** desarrollo web + bases de datos (backend / fullstack)
- **Hobby de fin de semana:** Blender (3D), sin metas, solo por gusto

**Ritmo:** 1 hora al día, lunes a viernes, siempre a la misma hora.
**Mínimo diario:** 25 minutos (los días malos, con eso basta).

---

## 🗺️ Trayecto (12 semanas)

### Fase 1 — Fundamentos y POO (semanas 1–4)
_Sin IA para escribir código. Solo para pedir explicaciones o pistas._

- [ ] **Semana 1:** variables, tipos de datos, operadores, entrada/salida
- [ ] **Semana 2:** condicionales, bucles, funciones
- [ ] **Semana 3:** arreglos/listas, cadenas, recursión, cómo pensar un algoritmo (pseudocódigo primero)
- [ ] **Semana 4:** POO: clases, objetos, encapsulamiento, herencia, polimorfismo, interfaces

**Recursos:** [CS50x (Harvard)](https://cs50.harvard.edu/x/) · [Exercism](https://exercism.org/) · [HackerRank](https://www.hackerrank.com/)

📂 **Guía y tareas:** [fase-1/](fase-1/)

**Entregable:** carpeta `fase-1/` con mis ejercicios resueltos y una mini app de consola con clases (ej. gestión de una biblioteca).

---

### Fase 2 — Bases de datos y fundamentos del oficio (semanas 5–8)

- [ ] **Semana 5:** SQL básico: `SELECT`, `WHERE`, `ORDER BY`, `INSERT`, `UPDATE`, `DELETE`
- [ ] **Semana 6:** `JOIN`s, `GROUP BY`, funciones de agregación, subconsultas
- [ ] **Semana 7:** modelado: entidad-relación, normalización (1FN, 2FN, 3FN), llaves, índices
- [ ] **Semana 8:** Git bien usado (ramas, commits con sentido, merge) + cómo funciona la web (HTTP, cliente/servidor, qué es una API)

**Recursos:** [SQLBolt](https://sqlbolt.com/) · [Documentación PostgreSQL](https://www.postgresql.org/docs/) · [Learn Git Branching](https://learngitbranching.js.org/?locale=es_ES)

📂 **Guía y tareas:** [fase-2/](fase-2/)

**Entregable:** carpeta `fase-2/` con el diagrama E-R y el script SQL de la base de datos del proyecto final.

---

### Fase 3 — Proyecto propio: Sistema de Agua Potable v2 (semanas 9–12)
_Reconstruir el proyecto de vinculación, esta vez entendiendo cada línea._

- [ ] **Semana 11:** backend sencillo conectado a la base de datos (registro de usuarios, medidores, lecturas)
- [ ] **Semana 12:** cobros/facturación básica, pulir y documentar

📂 **Guía y tareas:** [proyecto-agua-potable/](proyecto-agua-potable/)

## 🤖 Cómo uso la IA en este repo

1. **Intento primero yo.** Si llevo unos 20 minutos atascado, recién ahí pregunto.
2. **Pido explicaciones, no soluciones.** Por ejemplo: _"¿por qué falla esto?"_ o _"dame una pista, no el código"_.
3. **No pego nada que no pueda explicar.**
4. Al terminar algo, le pido a la IA que **me haga preguntas** sobre mi propio código.

---

## 🔥 Reglas para no abandonar

- **Meta mínima ridícula:** 25 minutos. Si hago más, bien.
- **Misma hora siempre.** No espero tener ganas.
- **Nunca dos días seguidos sin estudiar.** Fallar uno es normal.
- **Un solo proyecto a la vez.** Las ideas nuevas van a la lista de abajo.
- **Mejor terminar algo feo que abandonar algo perfecto.**
- La semana 2–3 se pone aburrida. **Es normal, no es señal de dejarlo.**
